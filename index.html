Semangat Guyub “Cipta – Karya – Bersama”

Rukun Tetangga (RT) merupakan lembaga kemasyarakatan paling mendasar yang dibentuk untuk memelihara dan melestarikan nilai-nilai gotong royong, mempererat kerukunan hidup bertetangga, serta menjadi jembatan pelayanan administrasi dan aspirasi antara warga dengan pemerintah desa.

Di lingkungan RT.001 RW.013 Perum Graha Asri Sektor Graha Jababeka, Desa Simpangan, ruang lingkup kami mencakup penyelenggaraan pelayanan warga yang transparan, pengelolaan ketertiban dan keamanan lingkungan, pemeliharaan kebersihan fasilitas bersama, hingga pengembangan kerukunan sosial antarwarga yang harmonis, aman, dan berdaya.

Mari bersama-sama berkomitmen mewujudkan lingkungan hunian yang tertata dan penuh kepedulian melalui semangat “Cipta – Karya – Bersama”

Budaya gotong royong luhur dan wujud kepedulian warga dalam menjaga keamanan pemukiman serta kas paguyuban bersama.

Wadah Depan Rumah Setiap rumah menyediakan kaleng/wadah kecil uang jimpitan sukarela di pagar atau teras setiap Sabtu malam.
Penarikan Saat Ronda Petugas ronda mengambil koin jimpitan pada patroli pukul 22.00 WIB sembari memastikan keamanan rumah warga.

01
Pukul 21.00 WIB • Apel Pos Kamling

02
Pukul 22.00 WIB • Tarik Jimpitan & Patroli

Berkeliling mengambil uang jimpitan di rumah warga, memeriksa kondisi pagar/portal serta lingkungan sekitar.

03
Pukul 23.00 – 05.00 WIB • Gembok Portal

Mengunci portal utama akses keluar-masuk wilayah RT, patroli berkala setiap jam ganjil, dan stand-by di pos.

Panduan Membuat File .APK

1

Cara Termudah 1-Menit (PWABuilder):

1. Buka situs resmi PWABuilder.com di browser Anda.

2. Masukkan URL hosting web ini (misal via Vercel / GitHub Pages / Firebase Hosting).

3. Klik Generate Android App ➔ Unduh file .apk siap install di semua HP Android pengurus RT!

2

Install Langsung Sebagai Aplikasi Native (PWA Standalone):

Buka web ini di Google Chrome di HP Anda, lalu tekan titik tiga (⋮) di pojok kanan atas, kemudian pilih "Tambahkan ke Layar Utama" / "Install Aplikasi". Aplikasi akan terpasang di menu HP tanpa perlu mendownload dari Play Store.

3

Build APK Profesional (Capacitor / Android Studio):

Jalankan perintah npx @capacitor/cli create lalu copy file html/css/js ke folder www, dan jalankan npx cap build android.
