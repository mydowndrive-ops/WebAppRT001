# Aturan Otomatis Sinkronisasi GitHub

Setiap kali asisten selesai melakukan perubahan atau modifikasi kode (HTML, CSS, JS, aset, dll.), **SELALU** langsung sinkronkan perubahan tersebut ke remote GitHub (`git add`, `git commit -m "..."`, dan `git push origin main`) tanpa menunggu perintah tambahan dari pengguna, sehingga pengguna dapat langsung meninjau pembaruan secara live.
